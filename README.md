# Превью для ваших проектов

Тёмное превью ваших проектов в формате полноэкранной презентации. Каждый проект — отдельный слайд, переключение скроллом, свайпом или клавиатурой. С живым маскотом-привидением Бу.

## 🚀 Запуск

Из-за CORS `data.json` не загрузится при открытии через `file://`. Нужен локальный сервер:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Альтернативы: `npx serve` или расширение **Live Server** в VS Code.

## ✏️ Добавить проект

Откройте `data.json` и добавьте объект в массив:

```json
{
  "title": "Название",
  "description": "Описание",
  "link": "https://ссылка",
  "ghostQuote": "Фраза Бу про этот проект (необязательно)"
}
```

- `title`, `description`, `link` — обязательны.
- `ghostQuote` — если пусто (`""`) или пробел (`" "`), Бу скажет общую фразу.
- Финальный слайд добавляется автоматически в конец.

## 🎮 Управление

| Действие | Что делает |
|---|---|
| Колесо мыши / свайп | Переключение слайдов |
| `↑` `↓` `Пробел` | Переключение |
| `Home` / `End` | Первый / последний слайд |
| Клик по точке справа | Переход к слайду |

## 👻 Маскот Бу

Привидение в левом нижнем углу. Следит за курсором, моргает, задумывается (12 с), засыпает (22 с).

**Клики:**
- **1–2** — подпрыгивает, говорит фразу
- **3+** — телепортирует к случайному проекту с его `ghostQuote`
- **10** — секретный режим (розовое свечение + конфетти)

На Android при клике — вибрация.

## 🔧 Кастомизация

- **Фразы Бу** — объект `phrases` в `initGhost()` (`script.js`)
- **Финальный текст** — `FINAL_MESSAGE` в начале `script.js`
- **Акцентный цвет** — `#a8b8ff` в `style.css`
- **Частицы** — `particleCount` в `initParticles()`

## 🐛 Если что-то не работает

1. **«Не удалось загрузить»** — открыт через `file://`. Запустите сервер.
2. **Нет звука** — браузер блокирует до первого клика. Кликните на страницу.
3. **Старые стили после правок** — `Ctrl+Shift+R` (жёсткий сброс кеша).

## 🧩 Совместимость

Chrome, Edge, Firefox, Safari — свежие версии (2022+). Используется `dvh`, `backdrop-filter`, `AudioContext`.
